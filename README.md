## Arquivos do Projeto

- `index.html`: Página principal com navegação entre a página da disciplina e a loja.
- `disciplina.html`: Página com informações sobre a disciplina, horários de aula e formulário de contato.
- `produtos.html`: Página com catálogo de produtos, tabela de preços e formulário de cadastro.
- `img/`: Imagens utilizadas nas páginas.

Desenvolvido utilizando apenas HTML5 semântico, sem CSS ou JavaScript.
