# Exercício 1 - HTML (INF 321)

Atividades práticas da aula de introdução ao HTML da disciplina **INF 321 - Projeto e Desenvolvimento de Sistemas para a Web** (Universidade Federal de Viçosa - UFV).

- **Professor:** Lucas Vegi
- **Aluno:** Rafael Caetité
- **Período:** 2026/2

O exercício foi desenvolvido utilizando apenas **HTML semântico puro**, sem a aplicação de regras de estilo (CSS) ou scripts (JavaScript).

---

## Estrutura dos Arquivos

* `index.html` - Página inicial com links para as duas atividades
* `disciplina.html` - **Parte 1:** Página com dados da disciplina INF 321, tópicos, horários, links e formulário de contato
* `produtos.html` - **Parte 2:** Página de catálogo de produtos e formulário para cadastro
* `img/` - Imagens e fotos reais utilizadas nas páginas

---

## O que foi implementado

### 1. Página da disciplina (`disciplina.html`)
- Título da disciplina em `<h1>` e cabeçalho com `<header>`;
- Descrição da ementa e identificação do professor;
- Imagem e lista com os tópicos da matéria usando `<ul>`;
- Quadro com horários de aulas e atendimento utilizando `<table>`;
- Lista de links úteis para sites acadêmicos utilizando `<ol>` e `<a>`;
- Formulário de contato com campos `<input>`, `<textarea>` e `<button>`;
- Estruturação semântica com `<header>`, `<main>`, `<section>` e `<footer>`.

### 2. Página de produtos (`produtos.html`)
- Cabeçalho `<header>` com título `<h1>Produtos</h1>` e descrição da loja;
- Seção de produtos disponíveis contendo 3 itens com foto (`<img>`), nome (`<h3>`), preço e link para detalhes;
- Seção com formulário funcional para cadastrar novo produto;
- Rodapé `<footer>` com o texto solicitado (`Minha loja`).
